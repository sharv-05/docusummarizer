# Five-minute demo

1. Start Streamlit and click **Load sample transcript**.
2. Click **Analyze transcript** and show processing status, chunk count, token estimate, and cost estimate.
3. Walk through the Executive summary, Decisions, Action items, and Risks & topics tabs.
4. Download the JSON and PDF reports.
5. Upload a `.docx` or `.pdf` transcript to demonstrate the ingestion layer.
6. Set `LLM_PROVIDER=openai` only when a server-side API key is available; the mock mode is the default for free-tier demonstrations.
